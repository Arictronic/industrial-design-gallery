# Как устроены сайты производителей оборудования для станков с ЧПУ

Сравнительный дизайн-аудит для проекта «Спутник точности» · 3 ноября 2026 года

[Открыть галерею полностраничных снимков](https://arictronic.github.io/industrial-design-gallery/). Номера в галерее совпадают с номерами сайтов в таблицах.

## Основной вывод

Для «Спутника точности» я бы выбрал **светлую инженерную стилистику с реальной предметной съёмкой**. На первом экране стоит показать датчик в шпинделе или на рабочем столе станка, объяснить назначение оборудования и дать две устойчивые точки входа — «Каталог продукции» и «Помочь с подбором». Восемь изделий можно показать ниже в открытой сетке. Так пользователь увидит весь ассортимент и сможет обратиться за подбором, даже если пока знает только свою задачу.

Для визуального направления ближе всего BLUM и SICK. У BLUM крупный план раскрывает принцип работы датчика, у SICK цветовая плоскость отделяет текст от фотографии. Для структуры каталога полезны FANUC и BIG DAISHOWA. Для навигации по задачам — Marposs. Для сохранения слайдера с понятным ручным управлением — KEYENCE и Mazak.

## Как проводился обзор

В выборку вошли страницы производителей измерительного оборудования, систем ЧПУ, оснастки, станков и промышленной автоматики. В таблицах указаны конкретные страницы и версии, поэтому наблюдение по разделу продукции не переносится автоматически на главную сайта.

При наличии окна согласия использована кнопка полного принятия или доступное подтверждение. Оценка описывает интерфейсы и возможную применимость для проекта. Данные о конверсии и мобильная проверка в этот аудит не входят. Баннеры могут отличаться по дате и региону.

### Четыре визуальных направления

1. **Светлая инженерная витрина.** Белый и светло-серый фон, тёмный текст, один акцентный цвет, крупные фотографии на нейтральной подложке. Это основное направление для «Спутника точности». Существующий зелёный можно использовать для основной кнопки, активных состояний и маркеров, а графитовый — для текста и технических схем. [BLUM](https://www.blum-novotest.com/us/products/) · [FANUC](https://www.fanucamerica.com/products/cnc)
2. **Фирменный цвет и макросъёмка.** Цветовой блок с заголовком соседствует с крупным планом. Подходит для презентации небольшого изделия, когда важно одновременно показать наконечник, корпус и масштаб. [SICK](https://www.sick.com/us/en/) · [Mitutoyo](https://www.mitutoyo.com/)
3. **Тёмная промышленная витрина.** Большой кадр цеха или станка, белый текст, контрастные кнопки. Хорошо работает на страницах внедрений, где можно показать оборудование в производственной среде. На главной небольшие датчики потребуют направленного света и крупного кадрирования. [DMG MORI](https://en.dmgmori.com/) · [Hurco](https://www.hurco.com/)
4. **Каталог с несколькими точками входа.** Поиск, категории, документы и связь с инженером видны сразу. Подходит для посетителя с артикулом или понятной задачей. Для небольшой линейки достаточно нескольких хорошо подписанных входов. [BIG DAISHOWA](https://www.bigdaishowa.com/en) · [KEYENCE](https://www.keyence.com/) · [Marposs](https://www.marposs.com/eng/application/machine-tool-industry)

### Что сделать со слайдером

**Основной вариант — один статичный первый экран.** Весь ассортимент разместить сразу ниже. Так заголовок и кнопки будут на одном месте, а пользователь сможет сравнить модели в сетке. Это проектная гипотеза, которую следует проверять на макете.

**Вариант с сохранением карусели — до трёх сюжетов с ручным переключением.** Например, основная линейка, конкретное применение и внедрение, если для каждого есть отдельное качественное фото. Под баннером — подписанные переключатели. Каталог и подбор находятся в постоянном блоке. Если автопрокрутка сохраняется, нужны видимая пауза и сохранение ручного выбора. Проверить управление с клавиатуры и доступность кнопок на узком экране.

Для сравнения двух вариантов достаточно трёх заданий на макете: найти подходящее изделие по задаче, открыть технический документ и отправить запрос с известной моделью станка. Для каждого задания сравнить первый выбранный путь, число ошибочных переходов и время до нужной страницы. Для мобильного макета отдельно проверить, остаются ли заголовок и основные действия видимыми при высоком кадре и длинных названиях.

### С чего начать макет

Собрать один экран с реальным фото и постоянными кнопками, а следом — сетку каталога. Затем сравнить его с вариантом с коротким слайдером на той же фотографии, тексте и кнопках. Это позволит оценить сам способ подачи, прежде чем менять остальную главную.

### Что полезно для «Спутника точности»

- **Входы по задаче на первом экране.** ROEMHELD встраивает три постоянных входа в нижнюю часть баннера, Nakamura-Tome даёт два видимых сюжета, а Contrinex держит быстрые действия под промокадром. Для «Спутника точности» аналогом может стать постоянный ряд «Измерение детали», «Измерение инструмента» и «Помочь с подбором», если эти названия точно отражают каталог. [ROEMHELD](https://www.roemheld.de/en) · [Nakamura-Tome](https://www.nakamura-tome.com/) · [Contrinex](https://www.contrinex.com/)
- **Вкладки подходят для сравнения семейств.** У Kitamura вкладки меняют тип станка внутри каталога, а у Nikon видны все измерительные направления на одной сетке. При восьми изделиях стоит проверить, хватит ли общей сетки и коротких подписей. Вкладки полезны, когда у семейств действительно различаются параметры и сценарии. [Kitamura](https://www.kitamura-machinery.com/) · [Nikon Industrial Metrology](https://industry.nikon.com/en-us/)
- **Фото в работе и чистое предметное фото решают разные задачи.** HIWIN показывает компонент в руке и затем выводит изолированные изделия в каталог. ANCA использует фактуру металла как фон, сохраняя отдельную светлую панель текста. Для макета можно показать датчик в станке на главной, а карточки каталога собрать из изображений в одном масштабе и ракурсе. [HIWIN](https://hiwin.com/) · [ANCA](https://machines.anca.com/)
- **Документация может быть самостоятельным маршрутом.** У «ПАРМА Инструмент» каталоги показаны узнаваемыми обложками, а у НПФ «Сенсорика» PDF-каталоги доступны в шапке. На «Спутнике точности» имеет смысл связать общую страницу документов с паспортами и инструкциями в конкретных карточках. [ПАРМА Инструмент](https://parmainstrument.ru/catalog/) · [НПФ «Сенсорика»](https://sensorika.ru/)
